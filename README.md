# BeachBuds Alerts

Live Wessex Water storm overflow dashboard for beaches around Branksome, Bournemouth and Poole. The site is static and needs no API keys.

The only source of truth for the website is `site/`. That is what is served at https://coastwatch.beatbake.co.uk.

How the app works, which feeds it uses, how to update bathing water ratings, how spill alerts run, and how to deploy are all in [HANDOVER.md](HANDOVER.md). Start there.
